Create a Python file fizzbuzz.py with a function fizzbuzz(n) that returns a list of strings for the numbers 1 to n: "Fizz" for multiples of 3, "Buzz" for multiples of 5, "FizzBuzz" for multiples of both, and the number itself otherwise. When the file is run as a script it prints fizzbuzz(15), one item per line. Run it once to check the output.
